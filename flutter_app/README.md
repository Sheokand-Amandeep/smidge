# Smidge Flutter App

This is the primary Flutter implementation of Smidge, a local-first unit converter with general conversions, pinned conversions, density-aware cooking, glucose conversion, trades compound units, and static currency conversion.

For the full project README, see `../README.md`.

For architecture diagrams and module notes, see `../architecture.md`.

## Run

```sh
flutter pub get
flutter run
```

## Check

```sh
flutter analyze
flutter test
```
